- Policy/RC: `db15k_rc_policy_analysis.md`, `rc_policy_diagnostics.md`, `rc_policy_optimizer_ablation.md`, `table3_first_step_policy_saturation.md`.
- Strategy/ablation: `fixed_strategy_ablation.md`, `experiment_k_results.md`.
- Nhóm thử nghiệm L0–L9: các file `experiment_l*.md` ghi từng câu hỏi, cấu hình và phân tích tương ứng.
